# Flutter Study Group Management

Flutter와 서버를 이용한 스터디 그룹 관리 애플리케이션입니다.

## 프로젝트 구조

```
.
├── my_app/          # Flutter 모바일 애플리케이션
└── server/          # 백엔드 서버 (Node.js/Express)
```

## 개발 환경 설정

### 사전 요구사항

- Flutter SDK (3.0 이상)
- Dart SDK
- Node.js 및 npm
- Android Studio (Android 개발)
- Xcode (iOS 개발)

### Flutter 앱 설정

```bash
cd my_app
flutter pub get
flutter run
```

### 서버 설정

```bash
cd server
npm install
npm start
```

## 기능

- 스터디 그룹 관리
- 멤버 관리
- 일정 관리
